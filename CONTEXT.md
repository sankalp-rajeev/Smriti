## Architecture Decisions
- Build Android native with Kotlin and Jetpack Compose to match the PRD and demo needs.
- Keep all MVP core behavior offline with local data and no network APIs.
- Put Gemma behavior behind a `GemmaAgent` interface while requiring `RealGemmaAgent` for app-facing reasoning.
- Keep `MockGemmaAgent` only for deterministic tests and legacy fixtures.
- Use visible setup/retry states rather than fallback clinical output when RealGemma is unavailable.
- Use LiteRT-LM via a local filesystem `.litertlm` model path when the real integration begins; prefer app-private sideload/import for the multi-GB model and keep model files out of git.
- Treat the first LiteRT-LM dependency addition as a compatibility validation step only; do not enable inference or model loading until a separate model availability/load spike.
- Keep model availability separate from model loading: app-private file presence may be shown in Offline Proof, but `FOUND_NOT_LOADED` must still mean inference is disabled.
- Keep RealGemma text-only execution behind an injectable `RealGemmaTextClient`: prompt building and output parsing can be tested locally before any LiteRT-LM engine call is introduced.
- Keep LiteRT-backed text generation behind a disabled `LiteRtGemmaTextClient`; `EngineConfig` may be constructed, but Engine initialization remains manual-only and inference remains disabled.
- Keep LiteRT text inference behind explicit local setup; do not run inference on app startup.
- Keep `LiteRtEngineInitializationChecker` out of normal UI/app startup; only a separate approved/manual model-loading check may instantiate `Engine`.
- Keep `RealGemmaReadinessEvaluator` as the only readiness/activation decision layer; it documents why RealGemma is blocked or disabled without adding an activation switch.
- Use Kotlin 2.3.10 with the matching `org.jetbrains.kotlin.plugin.compose` Compose compiler Gradle plugin instead of the older `composeOptions.kotlinCompilerExtensionVersion` path.
- Use AGP 8.13.2 and Gradle 8.13 because Android's Kotlin support table requires AGP 8.13.2 for Kotlin 2.3.
- Use Room 2.8.4 so Room's annotation processor can handle newer Kotlin metadata from the upgraded toolchain and LiteRT-LM dependencies.
- Use KSP 2.3.7 for Room annotation processing; the app module no longer applies the Kotlin KAPT plugin.
- Keep direct Gemma audio blocked; input remains offline speech/manual transcript to RealGemma text reasoning.
- Use Room entities/DAOs as the local persistence boundary and seed demo data on first app launch.
- Use a simple in-app screen state machine instead of adding Navigation Compose for the first scaffold.
- Use a flat keyword `ProtocolRetriever` for protocol chunks until the P1 local RAG corpus is added.
