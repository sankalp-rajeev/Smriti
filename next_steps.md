- Do **not** claim direct Gemma 4 audio works. Current public LiteRT-LM Android/Kotlin path is blocked for direct audio.
- Do **not** add cloud APIs.
- Do **not** add runtime model downloads.
- Do **not** commit `.litertlm` model files.
- Do **not** commit audio files.
- Do **not** use PHI or real patient data.

- Do **not** diagnose or prescribe.
- CHW review/confirm/save remains mandatory.
- Normal non-submission build keeps `MockGemmaAgent` as the safe default.
- Filmed submission build can use RealGemma text reasoning when gated and model is present.
