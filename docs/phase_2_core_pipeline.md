# Phase 2 Core Pipeline

Phase 2 completes the local visit cycle for the normal demo path while keeping `MockGemmaAgent` as default.

## Pipeline Shape

```text
transcript input or offline speech fallback
-> SpeechToTextClient / transcript metadata
-> VisitReasoningPipeline
-> ProtocolRetriever with optional country/region context
-> GemmaAgent
-> VisitReasoningResult
-> ReviewScreen
-> CHW confirm/save
-> LocalVisitMemoryStore
-> supervisor summary
```

## SpeechToTextClient

`SpeechToTextClient` defines the transcript boundary:

- `TranscriptResult.Success`
- `TranscriptResult.Unavailable`
- `TranscriptResult.Error`
- `TranscriptMetadata`

The pipeline accepts direct transcript text first. If transcript text is present, ASR is skipped.

## SimulatedTranscriptClient

`SimulatedTranscriptClient` keeps the sample/manual transcript path deterministic and local. It is used for the reliable default demo path and for tests.

## AndroidOfflineSpeechRecognizerClient

`AndroidOfflineSpeechRecognizerClient` provides the live Android offline-preferred fallback:

- Checks `SpeechRecognizer.isRecognitionAvailable(context)`.
- Checks `SpeechRecognizer.isOnDeviceRecognitionAvailable(context)` when available.
- Prefers `createOnDeviceSpeechRecognizer(context)`.
- Falls back to `createSpeechRecognizer(context)` with `RecognizerIntent.EXTRA_PREFER_OFFLINE=true`.
- Tries language tags in order: `en-IN`, `en-US`, `en`.
- Retries only for language unavailable/not-supported errors.
- Maps error 13 to friendly UI text: `Offline speech language pack unavailable on this device. Please type or use sample transcript.`
- Does not clear existing transcript on failure.
- On success, only fills the editable transcript field.
- Does not auto-generate a note.
- Does not save anything.
- Does not add cloud ASR.

Stored `.m4a` transcription is still unavailable because Android `SpeechRecognizer` does not provide a reliable app-private audio-file transcription route in this implementation.

## VisitReasoningPipeline

`VisitReasoningPipeline` coordinates:

- patient,
- prior visits,
- transcript text or audio path,
- local protocol retrieval,
- optional protocol country/region context,
- injected `GemmaAgent`,
- structured `VisitReasoningResult`.

It does not write to Room. It returns warnings/unavailable reasons when transcript resolution fails.

The default demo context is India-focused and still falls back to global protocol chunks when country-specific chunks are absent.

## LocalVisitMemoryStore

`LocalVisitMemoryStore` centralizes:

- demo seeding,
- confirmed visit save,
- referral flag save,
- refresh,
- reset demo data,
- history lookup.

It writes only after Review confirm/save.

## CHW Review, Confirm, Save

Generated output goes to `ReviewScreen`, where the CHW can edit:

- structured note,
- suggested follow-up,
- referral/citation presentation.

Only `onConfirmSave` calls `LocalVisitMemoryStore.saveConfirmedVisit(...)`. Speech recognition and generation do not save.

## Return-History Behavior

After confirm/save:

- local state is refreshed from DAOs,
- the saved visit is included in later patient history,
- Meena's latest confirmed visit appears before older seeded history.

## Referral Persistence

Referral flags:

- are generated by reasoning output,
- are not persisted before confirmation,
- are inserted only during `saveConfirmedVisit(...)`,
- are linked to the saved visit id.

## Supervisor Summary

Supervisor summary:

- reads fresh confirmed local visits and referrals,
- counts total confirmed visits,
- counts referral flags,
- shows concise urgent cases,
- keeps only the latest urgent case per patient,
- avoids repeated long raw protocol paragraphs.

## Reset Demo Data

Reset Demo Data:

- deletes saved referral flags,
- deletes saved visit logs,
- restores seeded patients,
- restores seeded Meena history,
- reloads protocol chunks,
- regenerates the summary from the clean snapshot.

Key unit tests:

- `VisitReasoningPipelineTest`

- `LocalVisitMemoryStoreTest`

- `AgentModeTest`
- `RealGemmaReadinessEvaluatorTest`
- `ManualInferenceWiringSafetyTest`
- `RepoModelArtifactSafetyTest`

Covered behavior:

- sample danger-sign transcript produces referral/citation/safety wording,
- normal ANC transcript does not create a false referral,
- incomplete observation stays uncertain and asks for clarification,
- no save before CHW confirmation,
- confirmed save updates patient history,
- referral persists only after confirmation,
- supervisor summary uses latest-per-patient urgent cases,
- reset restores clean seeded state,
- `AgentConfig.DEFAULT_MODE` remains `MOCK`,
- RealGemma is not wired into normal UI,
- no cloud/model/download/audio artifact runtime path is added.
