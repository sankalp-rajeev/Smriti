# Deployment Guide

How a supervisor deploys Smriti to CHWs in the field:

1. Install APK via USB, APK share, or sideload.
2. Sideload model file via adb or device file manager. The supervisor receives the model file from the district health team.
3. Share patient JSON register via WhatsApp, Bluetooth, or USB.
4. CHW imports register on first launch with one tap to add all patients.
5. CHW selects their language preference.
6. Smriti is ready for field use. No internet is required after setup.

This is the realistic last-mile deployment model.

The model file is large, about 2.5GB, and distributed by supervisors outside the APK. This matches how health system digital tools are deployed in LMIC field settings.
